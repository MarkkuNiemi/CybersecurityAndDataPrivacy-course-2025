# Privacy Policy – Booking System (Provided with ChatGPT, but manually inspected)

This Privacy Policy explains how the Booking System processes personal data in accordance with the General Data Protection Regulation (GDPR).

## 1. Data Controller
This application is used for educational purposes. The data controller is the organization or student running this assignment environment.

## 2. Personal Data Collected
The application collects the following personal data:

- Email address  
- Password (stored securely using hashing)  
- Birthdate (used to verify that the user is at least 15 years old)  
- User role (reserver or administrator)

## 3. Purpose of Processing
Personal data is processed for the following purposes:

- Creating and managing user accounts  
- Allowing users to log in  
- Ensuring the age requirement (15+) for resource reservations  
- Managing resources and bookings  

No personal data is shown publicly.

## 4. Legal Basis
Processing of personal data is based on **GDPR Article 6(1)(b) – Contract**, as the data is necessary for providing the booking service.

## 5. Data Storage and Security
- Passwords are stored using secure hashing (e.g., BCrypt).  
- Data is stored locally within the assignment environment.  
- Access to data is restricted to authenticated users.  

## 6. Data Retention
Data is retained for as long as the user account exists within the local assignment environment.

## 7. User Rights
Under GDPR, users have the right to:

- access their personal data  
- request correction  
- request deletion  
- request restriction of processing  
- request data portability  
- object to processing  

These rights apply even though the educational version of the system does not implement automated tools for exercising them.

## 8. Cookies
The system uses only essential session cookies required for authentication.  
No tracking or third-party cookies are used.

## 9. Data Breaches
In the event of a personal data breach, the data controller must follow GDPR Articles 33 and 34, including notifying affected users and authorities when required.
